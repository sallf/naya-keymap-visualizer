# Contributing

Thanks for your interest in contributing to Naya Keymap Viewer!

## How to contribute

1. **Fork** the repository
2. **Create a branch** from `main` for your change
3. **Make your changes** and test locally (`npm run dev`)
4. **Open a pull request** against `main`

## Reporting issues

Open an issue on GitHub with a clear description of the bug or feature request. Include screenshots if relevant.

## Development setup

```bash
npm install
npm run dev
```

## Guidelines

- Keep PRs focused on a single change
- Test your changes locally before submitting
- Follow the existing code style
